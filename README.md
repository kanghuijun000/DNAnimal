# DNAnimal — Evolution Lab

하나의 생명체를 탄생시키고, 성장·변이·적응과 무작위 사건을 거쳐 생애를 기록하는 모바일 우선 생명 시뮬레이션입니다.

## 실행
GitHub Pages에 배포하면 별도 서버나 계정 없이 브라우저에서 실행할 수 있습니다.

1. 저장소의 **Settings → Pages**로 이동합니다.
2. Build and deployment의 Source를 **GitHub Actions**로 선택합니다.
3. main 브랜치에 변경 사항이 push되면 Pages 배포 workflow가 실행됩니다.

## 포함 기능
- 동물과 서식지, 개체 이름 선택
- 성장·변이·환경 적응 행동
- 행동마다 발생하는 상황 이벤트
- 자유로운 서식지 이동과 이동 위험
- 개체별 나이, 건강, 에너지, 특성 관리
- 사망 결과 및 생애 타임라인
- 사망 개체 전시관과 상세 기록
- 전시된 개체의 종과 특성을 기반으로 새 개체 생성
- 브라우저 localStorage 저장
- 오프라인 캐시를 지원하는 PWA

## 데이터
게임 데이터는 현재 사용 중인 브라우저의 localStorage에 저장됩니다. 브라우저 데이터 삭제 또는 다른 기기 사용 시 자동으로 동기화되지 않습니다. 중요한 기록은 브라우저 데이터를 삭제하기 전에 보존해 주세요.

## 현재 범위
번식, 세대 연결, 서버 동기화는 아직 포함하지 않았습니다.
